02 / Design decisions

Engineering workstreams

VM assessment

Evaluate guest support, disk formats, dependency maps, licensing and downtime requirements.

Compute

Plan CPU and memory sizing, node placement, capacity headroom and maintenance constraints.

Networking

Define primary and secondary networks, Multus attachments, IP allocation and reachability.

Persistent storage

Select storage with required access modes, snapshots and performance; check live-migration prerequisites.

Migration

Pilot representative virtual machines, validate guest boot and application health, and establish rollback conditions.

Day-two operations

Plan guest patching, backup, monitoring, maintenance and access governance.

03 / Acceptance criteria

Validation and operational readiness

  • Guest boot and application validation
  • Network and storage performance
  • Recovery tests and data integrity
  • Maintenance and migration compatibility

These are proposed validation criteria, not completed test results.
