Virtualization / Engineering guide

OpenShift Virtualization migration readiness

A migration plan must account for guest dependencies, storage behavior, network connectivity and recovery constraints.

01 / Practice

Inventory the guest estate

Capture operating systems, disk sizes, CPU and memory, network dependencies, application owners and supported migration paths.

02 / Practice

Validate infrastructure

Review virtualization-capable worker nodes, CSI access modes, storage performance, Multus networks and capacity for maintenance.

03 / Practice

Pilot and accept

Test representative VMs for boot, guest services, network reachability, data integrity and recovery. Confirm live migration prerequisites separately.

Practical example

Lab and review reference

oc api-resources --api-group=kubevirt.io
oc get vm,vmi -A
oc get storageclass
oc api-resources --api-group=k8s.cni.cncf.io

Commands assume the relevant virtualization and Multus APIs are installed. Verify support and requirements for the deployed OpenShift Virtualization release.
